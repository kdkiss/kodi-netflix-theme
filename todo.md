## 5. Acceptance tests and packaging

Use a disposable desktop profile with a few playable films and episodes, including one partially watched item of each type, a finished title and a title missing fanart. For the provider checks, use an already available video add-on with a browsable folder and playable entry. Run these journeys again on the Stick with the actual remote.

| Check | Pass condition |
| --- | --- |
| A. Empty installation | Kodi opens to a visible browse action. Video files, Video add-ons and Settings can all be reached with the D-pad, Select and Back. |
| B. Movie night | Home → movie → details → Play → stop → Resume works with the expected file and saved position. Focus returns to a valid card. |
| C. Series night | TV Shows → show → season → episode plays the selected episode. Back returns through the correct parents. |
| D. Add-ons only | With no library titles, choose an add-on folder, restart Kodi, browse its shelf, enter a nested folder and play a title. Clear the source and browse Video add-ons again. |
| E. Mixed and unavailable sources | Library shelves and the configured add-on shelf coexist. A slow or missing provider leaves Settings and local titles usable. Missing progress or art displays a sensible fallback. |
| F. Navigation under load | From the first card, press Right ten times and then Left ten times. Repeat after art is cached. Focus is visible throughout and ends on the expected item. Down skips empty shelves. No repeated pause of one second or more on warm local shelves. |
| G. Device lifecycle | Switch away with Fire TV Home, reopen Kodi, then perform a full Kodi restart. Verify the selected skin, saved shelf, usable focus and working playback. |
| H. Install and rollback | Install the exact release ZIP from a Kodi-readable network share or local folder. Accept the skin change. Switch back through Settings → Interface → Skin and confirm Estuary opens with the same sources and library. |
